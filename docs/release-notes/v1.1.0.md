# IG Video Controller 1.1.0

New overlay control. No change in shortcuts or permissions.

## New
- **Play/pause button** to the left of the progress bar. In the main feed, clicking the video opens the post; this button pauses or resumes the video without leaving the feed.
  - The icon follows the video state: ▶ when paused, ❚❚ when playing. It also updates when you pause with `V` or through Instagram itself.
  - Clicking it does not open the post or trigger any other Instagram action.

## Privacy
Unchanged: no permissions declared, access only to `www.instagram.com`, no network, no storage and no keystroke logging.

## Installation / update
1. Download and extract `ig-video-controller.zip` (attached below).
2. Open `chrome://extensions` and turn on **Developer mode**.
3. If an earlier version is installed, remove it, or replace its folder contents and click the reload icon on the extension card.
4. Otherwise, click **Load unpacked** and select the extracted folder.

The full test checklist is in the [README](https://github.com/AlanRedael/IG-Video-Controller#test-checklist).
