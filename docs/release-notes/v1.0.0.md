# IG Video Controller 1.0.0

First release of **IG Video Controller**: a Chrome extension that adds speed control, skip back/forward and an interactive progress bar to Instagram videos (feed, Reels and Stories).

## Features
- Shortcuts: `R` 1x · `G` 1.5x · `H` 2x · `S`/`D` −/+0.25x · `Z`/`X` −/+5 s · `V` pause/resume
- Speed between 0.25x and 4x, kept when you switch Reels during the session
- Overlay at the bottom edge of the video with the time, the speed and the `1x`/`1,5x`/`2x` buttons
- Thin, Facebook-style progress bar: shows on hover or while the video is paused, with a handle for scrubbing

## Privacy
- No permissions declared; the only access is to `www.instagram.com`
- No network, no storage and no keystroke logging
- All code in a single readable file (`content.js`), with no dependencies

## Installation
1. Download and extract `ig-video-controller.zip` (attached below).
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the extracted folder.

The full test checklist is in the [README](https://github.com/AlanRedael/IG-Video-Controller#test-checklist).
