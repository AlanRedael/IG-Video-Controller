# IG Video Controller 1.0.1

Maintenance release. No change in behavior, shortcuts or permissions.

## Changes
- The extension description shown in `chrome://extensions` is now in English: *"Speed and navigation controls for Instagram videos. Does not collect or transmit any data."*
- Code comments translated to English (no runtime change).

## Privacy
Unchanged: no permissions declared, access only to `www.instagram.com`, no network, no storage and no keystroke logging.

## Installation / update
1. Download and extract `ig-video-controller.zip` (attached below).
2. Open `chrome://extensions` and turn on **Developer mode**.
3. If 1.0.0 is installed, remove it, or replace its folder contents and click the reload icon on the extension card.
4. Otherwise, click **Load unpacked** and select the extracted folder.

The full test checklist is in the [README](https://github.com/AlanRedael/IG-Video-Controller#test-checklist).
